# AI Interview Assistant – Chrome Extension

An AI-powered Chrome extension designed to simplify job description analysis and interview preparation using Google's Gemini API.

## Features

- **Job Description Analysis:** Extracts and analyzes job information from the current webpage.
- **Skill Identification:** Identifies required technical and soft skills.
- **Interview Questions:** Generates job-specific interview questions.
- **Preparation Tips:** Provides useful interview preparation suggestions.
- **AI Integration:** Uses Google Gemini API for intelligent analysis.
- **Chrome Integration:** Built using Chrome Extension Manifest V3 APIs.

## Technologies Used

- HTML
- CSS
- JavaScript
- Chrome Extension APIs
- Google Gemini API

## Installation

1. Clone or download this repository.
2. Open Google Chrome.
3. Navigate to `chrome://extensions/`.
4. Enable Developer Mode.
5. Click **Load unpacked**.
6. Select the project folder.
7. Open extension settings and enter your Gemini API key.

## Note

Users must provide their own Gemini API key. API keys are stored locally in Chrome extension storage.
